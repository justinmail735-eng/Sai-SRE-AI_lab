## Milestone 2 — Kubernetes and Helm

- Added a reusable Helm chart for the checkout workload.
- Added startup, readiness, and liveness probes.
- Added non-root execution, RuntimeDefault seccomp, read-only root filesystem,
  dropped capabilities, and disabled service-account token mounting.
- Added requests/limits, HPA, PodDisruptionBudget, NetworkPolicy, topology
  spreading, preferred anti-affinity, and zero-unavailable rolling updates.
- Created a three-node Kind cluster and installed the chart.
- Verified two healthy replicas running on separate worker nodes.
- Verified the hardened runtime settings from live Pod specifications.
- Verified in-cluster service networking with a real request.
- Added manifest and live-cluster jobs to continuous integration.
- Expanded the full test suite to 149 passing tests.

During validation, a strict topology constraint initially deadlocked a rolling
update because a tainted control-plane node was counted as an empty topology
domain. The chart now explicitly honors node taints and affinity when calculating
eligible topology domains. The corrected rollout completed with one replica on
each worker node.
