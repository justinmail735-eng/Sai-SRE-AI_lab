# SentinelSRE portfolio

The hosted presentation layer turns the repository's verified local evidence
into an interview-friendly command center. Its interactive approval replay uses
the same seeded roles, request identifier, measured Pod recovery, and explicit
scope boundaries as the checked-in agent and chaos evidence.

```bash
npm install
npm test
```

The UI does not connect to production systems. AWS EKS and Azure AKS are shown
as plan-tested Terraform foundations; live cloud telemetry remains future work.
